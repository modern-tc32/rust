# `tc32-unknown-none-elf`

**Tier: 3**

Bare-metal target for Telink TC32 microcontrollers (for example the TLSR82xx
family). TC32 is a Thumb-like 16-bit instruction set with 32-bit registers.

The target is exposed as `target_arch = "tc32"`. It reuses the ARM calling
convention, target feature tables and inline assembly register model, and the
code is generated by an LLVM with TC32 support (the `tc32` triple in LLVM's ARM
backend). Only `core` and `alloc` are supported; there is no `std`, no
unwinding (`panic = "abort"`) and no operating system.

## Target maintainers

This target is maintained out of tree in the
[`modern-tc32/rust`](https://github.com/modern-tc32/rust) fork.

## Requirements

* Static, non-PIC code (`relocation-model = "static"`), linked with `rust-lld`.
* Soft-float ABI and `+strict-align`: the core has no FPU and does not support
  unaligned accesses.
* Atomics: there are no compare-and-swap instructions (`atomic_cas = false`) and
  the maximum atomic width is 32 bits. The target is marked single-threaded, so
  atomic loads, stores and read-modify-write operations are emitted with the
  single-thread sync scope.
* `c_enum_min_bits` is 8, i.e. C-like enums are at least one byte wide.
* Inline assembly (`asm!`, `global_asm!`, `naked_asm!`) accepts the vendor
  mnemonics (`tmov`, `tloadr`, `tjex`, ...) in addition to Thumb-style ones.
  Only the general purpose register class `reg` is available; there are no
  floating point or vector registers.

## Building the target

This target needs an LLVM that supports TC32, so a pre-built CI LLVM cannot be
used. Point `bootstrap.toml` at a locally built LLVM:

```toml
[llvm]
download-ci-llvm = false

[build]
target = ["tc32-unknown-none-elf"]

[target.aarch64-apple-darwin] # use your host triple
llvm-config = "/path/to/tc32-llvm/bin/llvm-config"
```

Then build the standard library crates:

```sh
./x.py build --stage 2 --target tc32-unknown-none-elf library/core library/alloc library/compiler-builtins
```

## Building Rust programs

The target does not ship a prebuilt standard library. Build `core` and `alloc`
yourself with `-Zbuild-std`:

```sh
cargo +stage2 build -Zbuild-std=core,alloc,compiler_builtins --target tc32-unknown-none-elf
```

You will need a linker script and start-up code for your chip.

## Testing

The target cannot run the Rust test suite. The UI test
`tests/ui/asm/tc32-inline-syntax.rs` checks that the inline assembly surface
builds, and `tests/assembly-llvm/targets/targets-elf.rs` checks code
generation for the target.

## Cross-compilation toolchains and C code

C code for the target is built with the TC32 `clang` from the same LLVM that
rustc uses, using the `tc32-unknown-none-elf` triple.
